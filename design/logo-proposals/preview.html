Everyday Fitness — Brand

Logo proposals

Four directions, all built from tokens already in DESIGN.md — Barlow Condensed, Inter, the coral accent, and the rounded-square/pill shape language. No new icon set, illustration, or gradient (Principle 2). Each tile shows the mark on both the light-paper and dark-charcoal grounds it actually has to survive on.

Where we're starting from

public/favicon.svg and the PWA icons are a generic purple/violet gradient mark (#863bff / #7e14ff / #47bfff) — looks like a starter-template placeholder. It shares no color, shape, or type with the warm-paper / cool-ink / coral palette in DESIGN.md §2. None of the proposals below build on it; all four start clean from the actual system.

A — Wordmark, full stop

Type only

The plainest reading of Principle 2 — identity lives in type and color, not chrome. One line, Barlow Condensed 600, sentence case. The accent lands on a single piece of punctuation, so it reads as confident rather than shouty at any size.

D — Daily-check wordmark

Type + reused glyph

The small mark is the exact checkmark path already drawn by the Save-confirmation animation in LogScreen.tsx — not a new icon. It stands for "you showed up today," never a verdict on the number, so it stays inside §5/§6's no-judgment rule in a way a trend arrow couldn't.

A starting recommendation

B for the wordmark, C for the icon. B is the only option that actively reinforces an existing pattern rather than adding a new one — it costs nothing to learn. C is there because something square and legible at 16–32px is a real, separate requirement (browser tab, home screen) that a wordmark alone can't satisfy.

A and D stay on the table as alternates — A if a single-line lockup is needed for tight header space, D if the product wants the logo itself to carry a small piece of the app's own motion language.
